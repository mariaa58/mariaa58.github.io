Detailed Description

Classe Carona: herda de Compromisso, já que toda carona é um compromisso na agenda, porém possui informações adicionais específicas. Essa herança permite tratar caronas como compromissos em contextos onde não é necessário diferenciar, mas também acessar os detalhes específicos de uma carona quando necessário.
