Classe \doxylink{classGerenciador}{Gerenciador}\+: responsável por gerencia a lógica, o funcionamento dos menus e o fluxo do sistema. Centraliza a navegação, a interação do usuário pelos menus e outras operações, como o login. Seguindo a lógica de modularização, a criação de uma classe específica para isso melhora a organização do código e facilita futuras manutenções. Essa classe não armazena nenhum dado, apenas manipula objetos já existentes (usando ponteiros, por exemplo), executando ações de acordo com as opções escolhidas pelo usuário.

\doxysubsection{Detailed Description}
Classe \doxylink{classGerenciador}{Gerenciador}\+: responsável por gerencia a lógica, o funcionamento dos menus e o fluxo do sistema. Centraliza a navegação, a interação do usuário pelos menus e outras operações, como o login. Seguindo a lógica de modularização, a criação de uma classe específica para isso melhora a organização do código e facilita futuras manutenções. Essa classe não armazena nenhum dado, apenas manipula objetos já existentes (usando ponteiros, por exemplo), executando ações de acordo com as opções escolhidas pelo usuário.
