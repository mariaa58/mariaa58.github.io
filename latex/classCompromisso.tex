Classe \doxylink{classCompromisso}{Compromisso}\+: classe base para todos os tipos de compromissos do sistema, representando qualquer atividade que pode ser colocados na agenda do aluno, como caronas e eventos. Esta classe é a base de herança, com métodos fundamentais que todo compromisso deve ter, e permitindo que classes derivadas aumentem a funcionalidade. Facilita o polimorfismo\+: tratar diferentes tipos de compromisso de forma unificada, enquanto cada tipo de compromisso epode exibir ou manipular suas informações de maneira personalizada.

\doxysubsection{Detailed Description}
Classe \doxylink{classCompromisso}{Compromisso}\+: classe base para todos os tipos de compromissos do sistema, representando qualquer atividade que pode ser colocados na agenda do aluno, como caronas e eventos. Esta classe é a base de herança, com métodos fundamentais que todo compromisso deve ter, e permitindo que classes derivadas aumentem a funcionalidade. Facilita o polimorfismo\+: tratar diferentes tipos de compromisso de forma unificada, enquanto cada tipo de compromisso epode exibir ou manipular suas informações de maneira personalizada.
